# Public Brand Assets

Tracked canonical runtime assets for the CP and the n8n creative workflow.

- Source after Git pull: `public/assets/`
- Build output after `npm run build`: `dist-client/assets/`
- Public URL while the CP is running: `/assets/`
- Asset IDs and marketing approval status: `brand-profile.json`

The 3 L and 17 L renders are retained as source assets but are not approved for current marketing. Workflow asset resolution must reject entries where `approved_for_marketing` is `false`.

For an n8n filesystem mount, mount the Plesk checkout's `public/assets` directory read-only at `/data/brand-assets`. Do not mount `dist-client/assets`; it is regenerated by every build.
